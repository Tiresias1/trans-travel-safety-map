# Country-comparison audit and bounded pilot — handoff

## Non-negotiable requirements

- A country's rating is its own country assessment. ADM1 scores must **not** be averaged or otherwise used to change it. The user permits a summary of relevant additional regional restrictions/protections as blind comparison input; that is distinct from arithmetic feedback from ADM1 ratings. Do not add that summary without a reviewed, general method.
- ADM1 blind comparisons should start with the **full national comparison level**, then assess local additions/protections. Do not infer that this is implemented just because display text mentions the national government; trace the actual production input and scoring algorithm. This ADM1 question is separate from why a country got its rating.
- Score only trans-specific visitor risk, not general travel risk or unrelated LGBQ issues. 0.00 specifically means an outed trans visitor faces near-certain imprisonment **and likely execution**. Intermediate points are deliberately undefined; do not turn descriptions of 0.27 into new binding anchors or treat band labels as endpoint definitions. Avoid credit for passing/stealth.
- Social friction/curiosity is not the same as social hostility depicting trans people as threats, and neither is state threat-framing. Check the evidence and visitor applicability instead of applying keyword labels.
- Do not modify scores, re-rate at scale, change methodology, pick new anchors, invent an aggregate or insert development/provisional language into map popups. Report findings for review. No regex prose surgery; LLMs perform any approved prose rewrites and every change requires substantive verification.
- Do not use Grok or Muse. If writing code use a cheap subagent such as `xiaomi/mimo-v2.6-flash` with thinking=medium. No force-cache. One writer per checkout. Never commit API keys. Retain failures and contrary evidence.
